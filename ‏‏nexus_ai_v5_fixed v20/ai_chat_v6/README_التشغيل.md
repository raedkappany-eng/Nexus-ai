# دليل التشغيل السريع

## 1. ملخص المشاكل اللي كانت موجودة وتم حلها

- **"unauthorized" على ChatGPT و Claude**: الكود كان يتصل برابط قديم
  (`models.inference.ai.azure.com`) بأسماء موديلات قديمة. الرابط الصحيح
  الآن هو `models.github.ai/inference/chat/completions`، وأسماء
  الموديلات لازم يكون قبلها اسم الشركة (`openai/gpt-4o` مثلاً). بالإضافة
  إنه ملف `.env` اللي وصلني كان فيه نص "ضع التوكن هنا" بدل توكن حقيقي —
  تأكد إنه عندك محليًا فيه قيم حقيقية مو النص الافتراضي.
- **الموديلات ما كانت "تشوف" الصور**: كان بيترسل بس اسم الملف كنص
  ("المستخدم أرفق ملفًا")، مش الصورة نفسها. صار الكود يقرأ الصورة من
  القرص ويرسلها فعليًا لكل نموذج.
- **النجوم والرموز (** / ## ...) بالردود**: أضفنا تعليمات لكل نموذج
  إنه يجاوب بنص عادي بدون تنسيق، + طبقة تنظيف إضافية على الرد قبل ما
  يوصلك، حتى لو نموذج تجاهل التعليمات.
- **Gemini SDK قديم**: `google-generativeai` صار deprecated من جوجل،
  استبدلناه بـ `google-genai` الرسمي الجديد.

## 2. مين هو "Claude" و"ChatGPT" فعليًا بهاد الكود؟

هاد الكود ما بيتصل بـ Anthropic ولا OpenAI مباشرة، وما في اشتراك مجاني
حقيقي لـ Claude الفعلي بالسوق. اللي بيصير:

- تبويب **ChatGPT** = فعليًا GPT-4o الحقيقي من OpenAI، بس عم توصله
  مجانًا عبر خدمة GitHub Models (بحدود استخدام).
- تبويب **Claude** = فعليًا Llama 3.2 Vision من Meta (مش من Anthropic
  إطلاقًا)، لأنه ما في بديل مجاني حقيقي لكلود.

هاي نقطة مهمة لازم تنتبهلها: إذا بتخطط تنشر التطبيق لناس تانية، خلي
بالك إنه عرض اسم "Claude" وشعار Anthropic على رد فعليًا من Llama ممكن
يكون مضلّل للمستخدمين. الخيارات:
1. تسيبه للاستخدام الشخصي/التجربة بس (مافي مشكلة).
2. تغيّر التسمية لشي صريح متل "Llama Vision" بدل "Claude".
3. تسوي حساب Anthropic API حقيقي (فيه رصيد تجريبي مجاني بسيط للحسابات
   الجديدة) لو بدك كلود الحقيقي فعلاً.

## 3. التشغيل محليًا

```bash
cd ai_chat_v2
pip install -r requirements.txt
```

### افتح ملف `.env` وحط فيه:

1. **gemini_key** — مفتاح مجاني من https://aistudio.google.com/apikey
2. **github_token** — من https://github.com/settings/tokens
   اختر "Generate new token (classic)"، ما تحتاج تحدد أي صلاحيات
   خاصة، وانسخه كما هو.
3. **jwt_secret_key** — موجود مسبقًا، سيبه متل ما هو.

### شغّل السيرفر:

```bash
uvicorn app.main:app --reload --port 8000
```

افتح المتصفح على `http://127.0.0.1:8000`

## 4. سؤالك عن "هل أي حدا رح يشوف الرسائل" لما ينشر أونلاين

- **الرسائل نفسها**: لا — كل رسائل مرتبطة بحساب المستخدم (`user_id`)
  بقاعدة البيانات، ومسار `/api/messages` ما بيرجع إلا رسائل صاحب
  التوكن نفسه. هاي كانت مصممة صح من البداية.
- **الصور والملفات المرفوعة**: هاي نقطة تحتاج انتباه. أي حدا معه رابط
  الملف (مثلاً `/uploads/xxxxx.png`) يقدر يفتحه بدون تسجيل دخول، لأن
  المجلد مكشوف بدون حماية. الاسم عشوائي وطويل (صعب حد يخمنه)، بس مش
  محمي بكلمة سر أو حساب. إذا بدك حماية أقوى (تسجيل دخول إجباري حتى لعرض
  الصور) خبرني وبنضيفها كخطوة تانية — بس هاد بيحتاج تغيير طريقة عرض
  الصور بالواجهة شوي.
- **قبل النشر أونلاين عمومًا**: غيّر `allowed_origins` بملف `.env`
  لدومينك الحقيقي بدل الإعداد الافتراضي المحلي، ولا ترفع ملف `.env`
  على GitHub أبدًا (تأكد إنه مضاف بملف `.gitignore`).

## 5. ملاحظة عن الحدود المجانية

GitHub Models مجاني بس فيه حد لعدد الطلبات بالدقيقة/اليوم (حسب
الموديل، عادة حوالي 10-15 طلب بالدقيقة). كافي للتجربة والاستخدام
الشخصي، بس لو التطبيق صار يستخدمه ناس كثار بنفس الوقت أونلاين ممكن
تواجه رسائل "تجاوزت الحد المسموح" — وقتها الحل يكون بترقية حساب GitHub
Copilot أو الرجوع لمفاتيح OpenAI/Anthropic مدفوعة.
